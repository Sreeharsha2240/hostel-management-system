# Sprint 1 testing and evidence

## Run locally

Install the dependencies from `requirements.txt`, configure the MySQL database as described in the README, and run:

```sh
python manage.py check
python manage.py test
```

The student suite covers authorized registration, duplicate IDs, updates that preserve the Student ID, search by ID, partial name and hostel, retained deactivation, allocation restrictions, role access, and a response-time check with 5,000 synthetic records. The hostel suite covers admin-only writes, hostel and room validation, automatic bed creation and capacity changes, and available-bed filtering by hostel, floor and room type while excluding occupied and maintenance beds.

## Saved CI evidence

The `Django Tests` workflow runs `python manage.py test` and uploads its captured output as the `sprint1-test-evidence-<commit>` artifact, including when tests fail. Open the workflow run associated with the pull request commit, then download that artifact to review the complete test output. Artifacts are retained for 30 days.

The evidence is generated by GitHub Actions for each commit; no result is asserted here without a corresponding run.
